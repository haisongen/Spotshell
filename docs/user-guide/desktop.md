# 桌面端使用指南

桌面端分为顶部栏、左侧主机区、中间终端区和右侧 AI 区。主机区与 AI 区都可以拖动边界调整宽度，也可以折叠。

## 顶部栏

| 控件 | 作用 |
| --- | --- |
| `文件` | 退出应用 |
| `编辑` | 撤销、重做、剪切、复制、粘贴和全选 |
| `视图` | 刷新、开发者工具、缩放和全屏 |
| `窗口` | 最小化、关闭窗口，并切换中文或 English |
| `帮助` | 查看关于信息 |
| `终端` | 进入主机、会话和 AI 操作区 |
| `知识库` | 进入环境配置、知识模块和回收站 |
| 钥匙状态图标 | 显示 API Key 是否已经配置 |
| 太阳/月亮图标 | 在浅色和深色主题之间切换 |
| 齿轮图标 | 打开设置 |

## 主机管理

![主机搜索、文件夹与主机备注界面](../assets/screenshots/host-management.png)

### 主机区按钮

| 操作 | 作用 |
| --- | --- |
| 标题旁的 `+` | 新建主机 |
| 搜索框 | 按主机名称、地址或用户名筛选 |
| 单击主机 | 查看连接信息和主机备注 |
| 双击主机 | 立即连接 |
| `连接` | 打开新的 SSH 会话 |
| `...` 或右键主机 | 打开连接、测试连接、编辑、移动到文件夹和删除操作 |
| 右键文件夹 | 重命名、新建子文件夹、新建主机或删除文件夹 |
| 拖动主机 | 把主机移动到目标文件夹；拖到根区域可移回主目录 |
| `<` / `>` | 折叠或展开主机区 |

删除文件夹不会删除其中的主机和子文件夹，它们会移到上一级；发生同名冲突时操作会停止并提示处理。

### 新建或编辑主机

| 字段 | 说明 |
| --- | --- |
| 名称 | 列表中显示的名称 |
| 主机 | IP 地址或域名 |
| 端口 | SSH 端口，通常为 `22` |
| 用户名 | 登录用户 |
| 认证方式 | 私钥、密码或 SSH Agent |
| 私钥路径 | 使用私钥认证时填写本机私钥文件路径 |
| 自动环境 | 连接后自动选择的环境配置；也可以不绑定 |
| 主机备注 | 仅属于该主机的说明，会作为 AI 上下文的一部分 |

编辑已有主机时可点击 `测试连接`，用尚未保存的表单内容测试地址、认证与延迟。保存的密码和 API Key 不会显示回界面；更换认证方式时，界面会要求确认是否清除已有密码。

### 首次连接

第一次连接某个 `主机:端口` 时会显示服务器指纹。应与服务器管理员提供的指纹核对：

- `信任并连接`：记录指纹并继续。
- `取消`：中止连接，不记录指纹。

已记录的指纹发生变化时不要直接接受，应先确认服务器是否重装、密钥是否更换，排除中间人攻击。

## 会话与终端

连接成功后，每个 SSH 会话显示为一个标签。

![已连接的多会话 SSH 终端](../assets/screenshots/terminal-overview.png)

| 操作 | 作用 |
| --- | --- |
| 单击标签 | 切换当前会话 |
| 标签上的 `×` | 关闭该会话 |
| 标签栏的 `+` | 打开新连接窗口 |
| 右键标签 | 重命名、复制会话或关闭其他会话 |
| `Ctrl+Tab` | 切换到下一个会话 |
| `Ctrl+Shift+Tab` | 切换到上一个会话 |
| `Ctrl+W` | 关闭当前会话；焦点在表单或 AI 输入框时不会触发 |

标签状态会区分连接中、已连接、已断开和错误。连接断开后可在终端提示中选择 `重新连接` 或关闭会话。

终端内右键可使用：

| 操作 | 作用 |
| --- | --- |
| `复制` / `Ctrl+Shift+C` | 复制当前选中文本 |
| `粘贴` / `Ctrl+Shift+V` | 把剪贴板文本写入终端 |
| `询问 AI` | 将终端选中文本填入当前会话的 AI 输入框 |

## 设置

| 设置 | 作用 |
| --- | --- |
| 外观 | 选择深色或浅色主题 |
| OpenAI API Key | 配置 AI 服务凭据；留空会保留已有 Key |
| 清除 API Key | 删除本机保存的 Key |
| Base URL | 使用 OpenAI 兼容服务时填写接口根地址 |
| 模型 | 指定模型名称，默认 `gpt-4o-mini` |
| 上下文窗口 | 设置模型上下文容量，用于用量提示与压缩判断 |
| 递归上限 | 限制一次 Agent 任务的工具调用轮次 |
| Shell 集成 | 获取更准确的当前目录、最近命令、退出码和运行状态 |
| 自动压缩上下文 | 接近容量上限时，将较早内容压缩成可查看的摘要 |
| 测试连接 | 使用当前表单内容测试 AI 服务，不必先保存 |
| 保存 | 保存设置并关闭当前修改状态 |

右上角主题按钮只切换主题；语言在 `窗口 > 语言` 中切换。

## 本地数据

正式 Windows 版的数据位于 `%APPDATA%\SpotShell\`，包括主机树、设置、服务器指纹、知识数据和加密凭据。删除应用不会自动删除这些数据。
