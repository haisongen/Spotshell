# AI 助手使用指南

AI 面板始终绑定当前 SSH 标签。切换标签时，对话、执行策略、环境和知识上下文也随会话切换。

![AI 只读检查结果与写入命令审批](../assets/screenshots/ai-command-approval.png)

## 开始使用

1. 在 `设置` 中配置 API Key、Base URL 和模型，并点击 `测试连接`。
2. 连接 SSH 主机。
3. 在右侧输入问题，按 `Enter` 发送；按 `Shift+Enter` 换行。
4. Agent 工作时可点击 `停止` 取消当前请求。

终端中选中文本后右键选择 `询问 AI`，可以直接把错误输出或命令结果带入输入框。AI 回复中的命令提供“插入终端”和“运行”操作：前者只填入命令，后者进入执行策略判断。

## 顶部控件

| 控件 | 作用 |
| --- | --- |
| 执行策略下拉框 | 设置当前会话允许 AI 执行命令的范围 |
| `清除` | 清除当前标签的聊天记录和 Agent 历史 |
| `>` | 折叠 AI 面板；有待审批项目时，折叠按钮显示数量 |
| 环境选择 | 切换当前会话环境；可选择是否保存为该主机默认环境 |
| 图钉 | 将当前环境保存为主机默认环境或取消默认绑定 |
| 管理环境 | 跳转到知识库中的当前环境 |
| 知识计数 | 展开固定、已激活和可用知识模块 |
| `新上下文` | 保留可见聊天记录，但开始新的 Agent 上下文段 |

命令仍在运行时不能切换环境或开始新上下文，避免执行状态与上下文不一致。

## 执行策略

命令会先被分类为只读、写入或破坏性操作，再应用当前会话策略。

| 策略 | 只读命令 | 写入命令 | 破坏性命令 |
| --- | --- | --- | --- |
| `只读` | 自动执行 | 拒绝 | 拒绝 |
| `询问` | 自动执行 | 请求确认 | 请求确认 |
| `自动` | 自动执行 | 自动执行 | 请求确认 |

`自动` 不是无条件执行。删除、覆盖或其他破坏性命令仍会显示审批卡片。命令不透明、包含复杂替换或无法可靠解析时，会按更高风险处理。

审批卡片会显示拟执行命令和风险：

- `允许命令`：执行卡片中显示的命令。
- `拒绝命令`：不执行，并将拒绝结果返回给 Agent。
- 知识或主机备注提议：先查看内容或 diff，再保存、拒绝或选择目标位置。

不要只根据 AI 的说明审批，应直接检查卡片中的完整命令、参数、重定向和目标路径。

## 环境与知识上下文

AI 上下文由当前终端状态、主机备注、所选环境和知识模块组成。

| 分组 | 含义 | 可用操作 |
| --- | --- | --- |
| 固定 | 由环境固定加载的知识 | 查看和管理 |
| 已激活 | 当前上下文段已经按需加载的知识 | 卸载或固定 |
| 可用 | Agent 可以按任务需要加载的候选知识 | 加载或固定 |

知识出现新版本时，可以：

- `应用新版`：更新当前会话使用的版本。
- `保留当前`：本会话继续使用已有版本。

发布知识不会静默改变正在运行的 Agent 上下文；版本选择是显式操作。

## 对话与上下文容量

- 聊天记录只保留在当前应用运行期间，并随标签生命周期结束。
- `新上下文` 会插入分界线，清空短期 Agent 状态，但不删除可见历史。
- 可以引用旧上下文中的消息，将其快照带入当前上下文。
- 开启自动压缩后，接近模型容量时会生成可展开的摘要卡片；原聊天记录仍然可见。
- 用量表依据设置中的上下文窗口估算，模型配置不准确会影响提示时机。
